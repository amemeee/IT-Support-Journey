What you practise

  1. Triage

    Tickets arrive with priorities P1 to P4 and an SLA timer. New ones come in while you work, so you have to decide what to handle first.

  2. Asking questions

    Users don't always give you the useful detail. Ask for the error message, the computer name, and whether anyone else is affected. The right questions earn points.

  3. Account administration

    Unlock accounts, reset passwords and MFA, enable new hires, and manage group membership. Several users have very similar names.

  4. Network diagnosis

    Use ipconfig, ping, nslookup and /flushdns on a simulated PC. The output reflects what is actually wrong with it.

  5. Security judgement

    Identify phishing and social engineering. Resetting a password for someone you haven't verified costs more than any other mistake.

  6. Escalation

    Outages go to Infrastructure, incidents to Security, and hardware damage to Desktop L2. Escalating a ticket you could have fixed also costs points.

Commands behave like the real thing

Each simulated PC has its own state. A 169.254.x.x address means DHCP failed. If ping and nslookup return different addresses, the local DNS cache is stale. A hung print spooler has to be stopped before it will start again.

  • If the PC is offline, you get a guided session where the user runs commands for you.
  • Command history works with the up and down arrow keys.
  • The Software Center blocks software that needs a licence.

How a shift works

  1. Choose a mode. Standard mode has SLA timers, and hints cost points. Training mode has no timer.
  2. Open a ticket and talk to the user. Use the question buttons or type a question.
  3. Fix it or escalate it. Use Directory, Terminal and Remote, or send it to another team.
  4. Review the result. You see a points breakdown, the user's rating, and what the correct approach was.

Set in a Malaysian workplace

  • LanguageUsers write in English, Bahasa Malaysia and Manglish. Each question button also shows the BM phrase.
  • PDPAYou verify identity with a staff ID and never ask for a MyKad number, in line with the Personal Data Protection Act 2010.
  • Local scamsA fake LHDN e-Invoice email, and a caller claiming to be a "Dato'" who needs a password reset right away.
  • TimingLockouts after Raya leave, payroll and KWSP deadlines, and staff working from home on Unifi.
  • Namesbin, binti, a/l and a/p, and Chinese name order. Two users are called Nurul, and two more are Tan Wei Min and Tan Wei Ming.
